# Progetto Unico Group CMS

A complete Content Management System for Progetto Unico Group, featuring Galleria delle Idee, Ideal Casa Srl, and EdilCost.

## Features

- ✅ Complete website with responsive design
- ✅ Built-in admin panel (click the crown button)
- ✅ Manage hero section, about, companies, services, projects, brands, contact
- ✅ Change colors and design settings
- ✅ All data saved in your browser (localStorage)

## How to Use

1. Open `index.html` in your browser
2. Click the **crown button** (bottom right) to open admin panel
3. Make your changes
4. Click **Save** buttons
5. Refresh the page to see changes

## Default Login for Admin Panel

No login required - just click the crown button!

## Customization

- Change colors in Design tab
- Add/remove projects in Projects tab
- Add/remove services in Services tab
- Update company information

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome icons
